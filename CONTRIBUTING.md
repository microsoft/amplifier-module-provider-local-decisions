# Contributing

Contributions are welcome through pull requests. Run the focused checks described in README.md and explain behavior changes and their qualification limits. Keep ordinary model use available when optional decision support is absent.

Most contributions require agreement to the [Microsoft Contributor License Agreement](https://cla.opensource.microsoft.com/). The CLA bot will explain any required action on your pull request.

This project follows the [Microsoft Open Source Code of Conduct](CODE_OF_CONDUCT.md).
